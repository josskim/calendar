## 2026-08-01 — 예약 취소 시 외부 재고 해제 이벤트 보장

- 요청 원문: "staysync 앱, 캘린더 사이트로 PC나 모바일로 직접등록, 이 두가지 방법으로 캘린더에 예약을 등록하고있어. 이 2가지 방법으로 캘린더에 예약 등록 및 등록된 예약이 취소로 변경 저장되면.. 각 사이트에 예약 차단 및 예약 허용을 해주는 테스트를 할꺼야. 이제 워크등 완전히 기능 다 되도록 진행하자.. 다 준비되면 내가 테스트 데이터 입력해 볼께."
- 결과 요약:
  - StaySync 등록은 예약 생성과 같은 트랜잭션에서 `reservation.created` 이벤트를 생성하는 기존 경로를 확인했다.
  - PC·모바일 CalApp 직접 등록도 예약 생성과 같은 트랜잭션에서 `reservation.created` 이벤트를 생성하는 기존 경로를 확인했다.
  - 직접 등록 예약을 취소로 저장할 때 불필요한 중복 예약 검사가 취소 처리를 막지 않도록 수정했다.
  - 취소 저장은 변경 전·후 스냅샷을 포함한 `reservation.cancelled` 이벤트를 생성하므로 워커가 이전 날짜·호실의 판매를 다시 열 수 있다.
- 변경 파일:
  - `calapp/app/api/admin/reservations/route.ts`
- 검증:
  - `npm.cmd run build` 성공 (Next.js 프로덕션 빌드 및 TypeScript 검사)
  - GitHub `main` 푸시 완료, 운영 배포 대상에 반영
