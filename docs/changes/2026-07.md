## 2026-07-24 StaySync 모바일 예약 연동

### 요청 원문

> 모바일 문자와 휴대폰 연락처를 이용해 calendar/calapp 캘린더에 예약 내용을 기록하고
> 예약완료 처리하여 오버부킹을 막고 싶다.

> 폰에 저장된 "게스트 260811....." 이것도 오버부킹체크 하는데 사용해주면 좋아.
> 일단 펜션 오버부킹이 중요하니까 펜션만 집중하도록 하면 되고, goal 로해서 프로젝트
> 진행해줘.

### 결과 요약

- Bearer 토큰으로 보호되는 StaySync 모바일 전용 API를 추가했다.
- 101호, 201호, 202호 펜션 예약 입력만 허용하도록 검증한다.
- `[입실일, 퇴실일)` 기준으로 숙박 기간 전체의 기존 확정 예약 충돌을 검사한다.
- 여러 객실 검사와 등록을 Serializable 트랜잭션에서 처리한다.
- 충돌 시 HTTP 409와 기존 예약 목록을 반환하고 등록하지 않는다.
- StaySync 문자 참조값으로 동일 요청을 멱등 처리한다.
- 실제 입금자명은 예약자명으로, 휴대폰 연락처명은 비고로 저장한다.
- 등록 경로를 `staysync`로 기록하고 사용자가 확인한 문자 요약을 비고에 남긴다.

## 2026-07-25 StaySync 문자 예약 접수경로

### 요청 원문

> 문자에 바베큐서비스 이런 기타 내용이 있으면 캘린더 예약 완료시 비고에
> 내용도 추가해주고, 문자로 예약 되는건 캘린더에 접수경로(예약 사이트)를
> "전화"로 선택하면 돼.

### 결과 요약

- StaySync로 최종 등록되는 예약의 `source`를 `staysync`에서 `phone`으로 변경했다.
- 캘린더와 예약 목록 화면에서 해당 예약의 접수경로가 `전화`로 표시된다.
- StaySync 앱이 문자에서 추출한 `요청사항`은 기존 `rawSummary`를 통해 예약
  메모(비고)의 `문자 요약`에 함께 저장된다.
