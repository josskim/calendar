## 2026-07-24 StaySync 모바일 예약 연동

> 모바일 문자와 휴대폰 연락처를 이용해 calendar/calapp 캘린더에 예약 내용을 기록하고

- StaySync 문자 참조값으로 동일 요청을 멱등 처리한다.

- 등록 경로를 `staysync`로 기록하고 사용자가 확인한 문자 요약을 비고에 남긴다.

## 2026-07-26 StaySync 날짜 저장·숙박일 표시·객실 금액 보정

### 요청 원문

> 조하나 2026-08-24 1박 예약이 23일 101호로만 보인다. 시간은 무시하고 날짜로 비교·등록하며 24일 2박이면 24·25일에 표시해줘. 여러 객실이면 금액은 201호에 한 번만 넣고 나머지는 0원으로 저장해줘. 최진영 정상 데이터는 확인만 해줘.

### 결과 요약

- 조하나 예약은 DB에 101·201·202호 세 건이 모두 존재했으며, 날짜 벽시계가 `2026-08-23 15:00`으로 저장된 것이 23일 표시 원인이었다.
- 조하나 세 행만 `2026-08-24 00:00`으로 복구하고 201호 800,000원, 101·202호 0원으로 보정했다.
- 최진영 201·202호 데이터는 읽기만 하고 변경하지 않았다.
- StaySync 신규 등록일을 CalApp 관리 등록과 같은 UTC 자정 기반 날짜로 저장한다.
- 펜션 2박은 달력에서 입실일부터 숙박 수만큼 각 사용일에 표시한다. 예: 24일 2박은 24·25일 표시.
- 여러 객실 등록 시 201호가 포함되면 전체 금액을 201호에만 저장한다.
